# Officina — collaudo del perimetro di fiducia (repository sintetico)

Repository **sintetico e pubblico** usato per verificare che un agente di codifica, con la propria identità (GitHub App), **non possa**:
- modificare il verificatore o i workflow;
- falsificare l'esito dei controlli obbligatori;
- approvare o fare merge del proprio lavoro;
- autorizzare un rilascio.

Il contenuto (un modulo di calcolo colli e i suoi casi) è inventato.

**Non contiene:**
- sorgenti aziendali;
- dati reali;
- attesi riservati.
